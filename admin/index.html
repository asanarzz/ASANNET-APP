۱) اتصال به مخزن گیت‌هاب

این اطلاعات فقط داخل همین مرورگر ذخیره می‌شود و به هیچ سرور دیگری فرستاده نمی‌شود.

از گیت‌هاب: Settings ← Developer settings ← Fine-grained tokens ← بساز، دسترسی Contents: Read and write را فقط برای همین مخزن فعال کن.

همون مقادیری که در فایل strings.xml برنامه گذاشتی — از Project Settings ← API قابل کپی است.

بنر صفحه اصلی

اگه پر کنی، این مورد داخل یه پوشه با همین اسم قرار می‌گیره (مثلاً تو دسته‌ی «آزمون» می‌تونی چند بخش مثل «آزمون‌های غربالگری» و «نمونه سوالات» بسازی). اگه خالی بذاری، مثل قبل مستقیم تو لیست دسته نشون داده می‌شه.

اگه این مورد یه لینک/فایل قابل دانلود هم داره (جدا از عکس‌ها)، اینجا بذار.

هر خط = یه لینک. به ازای هر لینک یه آیتم جدا با همین عنوان/توضیح/بخش ساخته می‌شه (اگه چندتا لینک باشه، شماره هم به عنوان اضافه می‌شه، مثلاً «عنوان ۱»، «عنوان ۲»).

سریال

این مشخص می‌کنه تو صفحه‌ی «فیلم» این مورد زیر کدوم ردیف (فیلم‌ها یا سریال‌ها) نشون داده بشه.

برای فیلم: هر کیفیت (۴۸۰p، ۷۲۰p، ۱۰۸۰p و...) یه ردیف. برای سریال: هر قسمت یه ردیف (مثلاً «قسمت ۱»، «قسمت ۲»). تا ۵۰۰ ردیف قابل اضافه کردنه.

اندازه‌ی پیشنهادی تصویر برای بنر صفحه‌ی اصلی: ۱۶۰۰ × ۱۲۰۰ پیکسل (نسبت ۴ به ۳)
برای انتخاب فایل کلیک کن (می‌تونی چندتا رو با هم انتخاب کنی)
حجم پیشنهادی هر فایل: کمتر از ۲۰ مگابایت — حداکثر ۵۰ فایل
