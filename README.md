# کافی‌نت آسان‌نت 📱

یک سیستم دو بخشی:

1. **اپ اندروید** (پوشه‌ی `app/`) — قبل از هر چیز از کاربر ثبت‌نام می‌گیرد (نام، نام‌خانوادگی، کد ملی، موبایل، تاریخ تولد، رمز عبور)، بعد فقط نمایش‌دهنده است: کاربرها می‌توانند آزمون‌ها را انجام بدهند، لینک‌ها را باز کنند، عکس/ویدیو را ببینند و فایل‌ها را دانلود کنند. **هیچ راهی برای اضافه یا حذف کردن محتوا داخل خود اپ وجود ندارد** — کاملاً یک‌طرفه.
2. **پنل مدیریت** (پوشه‌ی `admin/`) — یک صفحه‌ی وب که فقط خودت (مدیر) بازش می‌کنی، از آن لینک/آزمون/عکس/ویدیو/فایل اضافه یا حذف می‌کنی. هر تغییری که بدهی مستقیم روی گیت‌هاب ذخیره می‌شود و **بدون نیاز به ساخت مجدد اپ**، خودش را به همه‌ی کسانی که اپ را نصب کرده‌اند نشان می‌دهد (چون اپ هر بار محتوا را از اینترنت می‌خواند).

---

## مرحله ۱ — ساخت ریپازیتوری

1. یک ریپازیتوری جدید در گیت‌هاب بساز (می‌تواند خصوصی هم باشد).
2. تمام فایل‌های این پوشه را push کن:
   ```bash
   cd kafinet-app
   git init
   git add .
   git commit -m "نسخه‌ی اولیه"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
   ```

## مرحله ۲ — وصل کردن اپ به محتوای آنلاین

1. لینک raw فایل `content.json` را بردار:
   ```
   https://raw.githubusercontent.com/USERNAME/REPO/main/content.json
   ```
2. این لینک را در `app/src/main/res/values/strings.xml` داخل مقدار `remote_content_url` بگذار.
3. تغییر را commit و push کن — GitHub Actions خودش APK را می‌سازد (توضیح در مرحله‌ی ۴).

## مرحله ۳ — راه‌اندازی پنل مدیریت (برای خودت)

پنل مدیریت یک فایل HTML ساده است که می‌توانی:
- مستقیم روی گوشی/کامپیوتر خودت بازش کنی (فایل `admin/index.html` را با مرورگر باز کن)، **یا**
- با GitHub Pages میزبانی‌اش کنی تا یک لینک ثابت داشته باشی:
  1. در ریپازیتوری برو به Settings ← Pages
  2. از قسمت Source گزینه‌ی «Deploy from a branch» را انتخاب کن، شاخه‌ی `main` و پوشه‌ی `/(root)` را بزن، Save کن.
  3. بعد از چند دقیقه پنل مدیریت در آدرس زیر در دسترس است:
     ```
     https://USERNAME.github.io/REPO/admin/
     ```

### ساخت توکن دسترسی (Personal Access Token)

پنل مدیریت برای ذخیره‌ی تغییرات روی گیت‌هاب به یک توکن نیاز دارد:

1. در گیت‌هاب: **Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token**
2. در قسمت Repository access فقط همین یک ریپازیتوری را انتخاب کن.
3. در قسمت Permissions ← Repository permissions، مقابل **Contents** گزینه‌ی **Read and write** را بزن.
4. توکن ساخته‌شده را کپی کن (فقط یک‌بار نشانش می‌دهد).

### استفاده از پنل

1. پنل را باز کن، نام کاربری، نام ریپازیتوری، نام شاخه (`main`) و توکن را وارد کن → «اتصال و ورود».
2. برای افزودن محتوا: نوع را انتخاب کن (لینک / آزمون HTML / عکس / ویدیو / فایل)، عنوان و توضیح را بنویس، بعد یا یک لینک بچسبان یا مستقیم فایل را از گوشی/کامپیوترت آپلود کن.
3. بزن «افزودن به برنامه» — همان لحظه تغییر روی گیت‌هاب ذخیره می‌شود.
4. هر کسی که اپ را روی گوشی‌اش دارد، با باز کردن اپ یا کشیدن صفحه به پایین (pull-to-refresh)، محتوای جدید را می‌بیند.

> نکته: این اطلاعات اتصال (توکن و غیره) فقط داخل مرورگر خودت ذخیره می‌شود و جای دیگری فرستاده نمی‌شود.
> نکته: آپلود مستقیم برای فایل‌های حجیم (ویدیوهای بزرگ) مناسب نیست؛ برای آن‌ها بهتر است لینک یک سرویس دیگر (مثل آپارات، تلگرام یا هر فضای دیگر) را در حالت «لینک» بچسبانی.

## مرحله ۴ — ساخت خودکار APK

با هر push به شاخه‌ی `main`، ورک‌فلوی گیت‌هاب اکشن به نام «Build Android APK» اجرا می‌شود:
- در تب **Actions**، بعد از پایان اجرا، در بخش Artifacts فایل `kafinet-debug-apk` را دانلود کن (zip شامل `app-debug.apk`).
- برای گرفتن APK در بخش **Releases** هم، یک تگ نسخه بزن:
  ```bash
  git tag v1.0
  git push origin v1.0
  ```

> چون اپ امضا نشده (debug) است، هنگام نصب باید «نصب از منابع ناشناس» را در گوشی فعال کنی.

## ثبت‌نام کاربران (اجباری قبل از ورود به اپ)

هر کسی که اپ را نصب کند، اول یک فرم ثبت‌نام می‌بیند (نام، نام خانوادگی، کد ملی، شماره موبایل، تاریخ تولد، رمز عبور) و باید یک‌بار آن را پر کند تا وارد لیست محتوا بشود. این اطلاعات در یک دیتابیس آنلاین رایگان به نام **Supabase** ذخیره می‌شود و تو می‌توانی از طریق پنل خود Supabase (بدون نیاز به ساخت چیز اضافه) لیست کامل ثبت‌نامی‌ها را ببینی. رمز عبور هرگز به‌صورت متن ساده ذخیره نمی‌شود (هش می‌شود).

### راه‌اندازی (یک‌بار)

1. در [supabase.com](https://supabase.com) یک حساب رایگان بساز و یک پروژه‌ی جدید بزن.
2. از منوی سمت چپ برو به **SQL Editor**، یک Query جدید بساز و این را اجرا کن:
   ```sql
   create table public.users (
     id uuid primary key default gen_random_uuid(),
     first_name text not null,
     last_name text not null,
     national_code text not null unique,
     phone_number text not null,
     birth_date text not null,
     password_hash text not null,
     created_at timestamptz not null default now()
   );

   alter table public.users enable row level security;

   create policy "Allow public insert"
     on public.users
     for insert
     to anon
     with check (true);
   ```
   (سیاست بالا فقط اجازه‌ی «ثبت‌نام» را به اپ می‌دهد — نه خواندن اطلاعات — یعنی هیچ کاربری از داخل اپ نمی‌تواند اطلاعات بقیه را ببیند. تو با ورود به داشبورد Supabase همیشه به همه‌چیز دسترسی داری.)

3. از منوی **Project Settings ← API**، دو مقدار زیر را کپی کن:
   - **Project URL**
   - **anon public key**

4. این دو مقدار را در `app/src/main/res/values/strings.xml` بگذار:
   ```xml
   <string name="supabase_url">https://xxxxxxxx.supabase.co</string>
   <string name="supabase_anon_key">eyJhbGciOi...</string>
   ```
5. Commit و push کن — اپ بعدی که ساخته شود، فرم ثبت‌نام فعال است.

### جلوگیری از خاموش‌شدن پروژه‌ی رایگان Supabase

پروژه‌های رایگان Supabase اگر ۷ روز هیچ درخواستی نگیرند، خودکار Pause می‌شوند. برای جلوگیری از این اتفاق، یک ورک‌فلوی گیت‌هاب اکشن (`.github/workflows/keep-supabase-alive.yml`) هر ۲ روز یک‌بار خودکار یک درخواست سبک به Supabase می‌زند — کاملاً رایگان، نیازی به کار دستی نیست. فقط باید دوتا Secret در ریپازیتوری تنظیم کنی:

1. در ریپازیتوری برو به **Settings ← Secrets and variables ← Actions ← New repository secret**
2. دو Secret زیر را بساز (همان مقادیری که در `strings.xml` گذاشتی):
   - نام: `SUPABASE_URL` — مقدار: همان Project URL
   - نام: `SUPABASE_ANON_KEY` — مقدار: همان anon public key
3. تمام — از این به بعد این ورک‌فلو خودش هر ۲ روز اجرا می‌شود. برای تست فوری، از تب Actions روی «Keep Supabase Project Alive ← Run workflow» بزن.

### دیدن لیست ثبت‌نامی‌ها

در داشبورد Supabase برو به **Table Editor ← users** — همان‌جا لیست کامل با همه‌ی فیلدها (به‌جز رمز عبور که هش‌شده است) نشان داده می‌شود؛ می‌توانی از همان صفحه هم فیلتر/جستجو/خروجی Excel بگیری.

## چطور آزمون HTML اضافه کنم؟

دو راه داری:

**از پنل مدیریت (ساده‌ترین راه):** نوع «آزمون HTML» را انتخاب کن، فایل `.html` را آپلود کن — خودش در پوشه‌ی `tests/` روی گیت‌هاب قرار می‌گیرد و لینکش را تنظیم می‌کند.

**دستی:** فایل HTML را در پوشه‌ی `tests/` (ریشه‌ی ریپازیتوری) بگذار، سپس در پنل یک آیتم از نوع «لینک» با آدرس raw همان فایل بساز.

## ساختار پروژه

```
kafinet-app/
  app/                    ← پروژه‌ی اندروید (فقط نمایش‌دهنده)
  admin/index.html        ← پنل مدیریت (فقط برای خودت)
  content.json            ← لیست زنده‌ی محتوا (با پنل ویرایش می‌شود)
  media/                  ← عکس/ویدیو/فایل‌های آپلودشده از پنل
  tests/                  ← آزمون‌های HTML آپلودشده از پنل
  .github/workflows/      ← ساخت خودکار APK
```

### انواع محتوا

| type    | کاربرد                                                        |
|---------|------------------------------------------------------------------|
| `test`  | آزمون HTML                                                     |
| `link`  | هر لینک وب — داخل اپ باز می‌شود                                |
| `image` | عکس — با دکمه‌ی دانلود قابل ذخیره است                          |
| `video` | کلیپ ویدیویی — پخش آنلاین + دکمه‌ی دانلود                      |
| `file`  | هر فرمت دیگر (pdf, docx, zip و…) — مستقیم در Downloads ذخیره می‌شود |
